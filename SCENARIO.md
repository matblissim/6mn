## Indices (gardés d'une boucle à l'autre)
- La rame chute à 22:00 (première boucle).
- Odile quitte son poste à 21:57:20 pour un café (l'observer ou le lui demander).
- Le gilet jaune fouille l'armoire du local quand Odile est absente (l'observer).
- Le frein de secours a été désarmé (regarder l'armoire après le passage du gilet jaune).
- Le gilet jaune n'est pas un agent (Mme Delattre connaît tout le personnel).
- Bastien cache un drone dans son sac (regarder le sac quand il est seul).

## Fins
- **Chute** : le frein est désarmé → la boucle recommence.
- **Sursis** : le sabotage est empêché (café apporté à Odile, ou gilet jaune dérangé) → la rame part, mais le saboteur s'en va ; la boucle recommence.
- **Alarme** : arrêt d'urgence → départ annulé, le saboteur file ; la boucle recommence.
- **Le dernier voyage** (vraie fin) : obtenir la preuve filmée par Bastien et la montrer à Odile → elle réarme le frein, le gilet jaune est retenu, la rame part sans danger. La boucle se brise.
